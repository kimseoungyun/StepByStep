# 보행 분석 개편 검증 기록

## 2026-10-28 실행 복구 및 재검증

CodeIntegrity 이벤트 3077에서 서명되지 않은 `.venv/Scripts/python.exe` 차단을 확인했습니다.
유효한 서명의 Codex 제공 Python 3.12.14는 정상 실행됐습니다. Windows 보안 정책은
변경하지 않고 해당 런타임과 프로젝트 전용 `.runtime-packages/`로 실행 환경을 구성했습니다.
재현용 `scripts/run.ps1`을 추가했으며 Django 검사와 테스트 2개를 통과했습니다.

실제 Chromium에서 새 카메라 조작 회귀 테스트를 실행했습니다.
빈 영상 58프레임은 모두 미검출, 정지 인체 샘플 57프레임은 모두 유효했습니다.
JSON/CSV 내보내기, 카메라 버튼 전환, 해제 후 재연결, 3초 이상 분석 후 해제 및
트랙 종료, 손상 파일 오류 처리가 통과했습니다. 브라우저 오류와 POST 요청은 0개였습니다.
카메라는 테스트용 가상 장치를 사용했으며 실제 사용자 카메라와 실제 보행 정확도는 별도 확인 대상입니다.
아래에 기록된 실행 차단으로 인한 미검증 상태는 이 재검증으로 해소됐습니다.

## 2026-10-28 카메라 조작 개선

연결 성공 시 버튼을 ‘카메라 해제’로 전환하고, 미리보기 및 분석 중에도 해제할 수 있게 했습니다.
분석 중 해제하면 수집된 샘플의 결과를 보존하며 트랙과 Worker를 종료합니다.
연결 준비 중에는 ‘연결 중…’을 표시하고, 장치 연결 종료 이벤트도 처리합니다.
브라우저 회귀 테스트에 연결·해제·재연결·분석 중 해제 검사를 추가했습니다.
JavaScript 구문 검사와 계산 테스트 10개는 통과했습니다.
이번 브라우저 테스트는 Windows 애플리케이션 제어 정책이 `.venv/Scripts/python.exe`를
차단하여 실행하지 못했습니다. 아래의 기존 브라우저 검증과 구분해야 합니다.

검증일: 2026-10-21. Windows, Python 3.12.14, Django 5.2.18, Node 24.19.0,
Playwright 1.64.0 / Chromium 156 환경에서 확인했습니다.

## 사용자 흐름

영상 파일 또는 브라우저 카메라 → Worker의 MediaPipe 추론 → 프레임별 2D 측정 →
품질 조건을 적용한 통계 → 화면 리포트와 JSON/CSV 다운로드.
Django는 화면과 정적 자산을 제공하며, 영상·관절·결과를 서버에 저장하지 않습니다.

| 경계 | 결과 | 근거 |
|---|---|---|
| Django → 화면 | 통과 | `manage.py check` 오류 없음. 홈·측정·기존 경로 테스트 2개 통과 |
| 관절 좌표 → 수치 | 통과 | Node 테스트 10개: 각도, 영상 비율, 결측, 정지, 교차 주기, 가림, 표본 부족, 이상치 |
| 브라우저 → 모델 | 통과 | 실제 CDN의 JS/WASM 및 Google Storage 모델을 로드하여 Chromium에서 추론 |
| 인체 미검출 → 결과 | 통과 | 생성한 빈 영상 53프레임, 유효 0프레임. 모든 지표 `null`, 측정 불가 안내 |
| 인체 검출 → 결과 | 통과 | 공개 자세 JPEG로 생성한 정지 영상 35프레임 모두 유효. 몸통 기울기 계산, 분당 걸음은 `null` |
| 결과 → 다운로드 | 통과 | JSON 파싱 및 표본 수 확인, CSV 행 수 = 샘플 수 + 헤더 |
| 종료·재시도 | 통과 | 초기화 중 종료 후 재시도 가능, 가상 카메라 트랙 `ended` 확인 |
| 손상 파일 → 오류 안내 | 통과 | 잘못된 WebM 거부, 분석 시작 버튼 비활성화 |
| 모바일 화면 | 통과 | 390px 너비에서 수평 넘침 없음, 데스크톱·모바일 스크린샷 확인 |
| 브라우저 오류·업로드 | 통과 | 완료 실행에서 page error 0개, POST 요청 0개 |

## 발견하여 수정한 문제

- 존재하지 않는 MediaPipe 버전 URL을 실제 제공되는 0.10.21로 고정했습니다.
- WASM 로더의 `importScripts`와 모듈형 Worker 충돌을 classic Worker + 동적 import로 해결했습니다.
- 카메라·파일 변경 시 이전 소스와 결과를 해제하고, 초기 안내 상태로 되돌리도록 처리했습니다.
- 기존 TensorFlow import 때문에 웹 화면까지 실행되지 않던 결합을 제거했습니다.
- 공용 결과 JSON을 다른 측정에 재사용하던 경로를 없앴습니다.

## 재현

실행·테스트 명령은 루트 README에 있습니다. 정지 자세 양성 테스트에 사용한 공개 자료:

## 검증하지 않은 범위

- 실제 보행 영상의 기준 걸음 수·관절 각도와 비교한 오차, 임상적 타당성
- 실제 카메라 하드웨어, Safari/Firefox, 여러 모바일 기기의 동작과 성능
- 여러 사람이 교대로 나타나는 영상의 동일 인물 추적, 촬영 방향 자동 검사
- 실제 길이·보행 속도, 인증된 결과 이력·QR 공유, 운영 배포
- 이전 PoseNet 대비 속도 개선 배율: 측정하지 않았으므로 주장하지 않음

프레임 수는 하드웨어·모델 로딩·영상 재생 타이밍에 따라 달라집니다.
정지 자세 샘플과 합성 관절 테스트의 통과를 실제 보행 정확도로 해석하면 안 됩니다.
